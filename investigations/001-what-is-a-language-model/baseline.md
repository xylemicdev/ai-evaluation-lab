# baseline

> this document captures my understanding before researching the topic. it isn't intended to be perfectly accurate. it's a snapshot of my thinking at the beginning of this investigation


## what do i currently think a language model is?

honestly, i think of it as something like a shape that got pressed into language

not a mind sitting behind the words, more like... if you took an enormous number of patterns in how humans put sentences together, every argument, every joke, every technical explanation, every awkward apology text, and compressed all of that into something that could regenerate a plausible next piece of it


that's closer to what i think it is

less "something that thinks and then speaks," and more "the speaking itself, shaped so well it sometimes looks like thinking from the outside"


## why do i think that?

mostly from using language models over time

the more i have interacted with them, the less i have felt like there is a mind behind the responses and the more it feels like an incredibly sophisticated system for generating language

i don't know exactly how it works internally, but i have started to separate fluent language from actual understanding


## what am i unsure about?

this explanation starts to feel incomplete when i think about questions the model has probably never seen before

if it isn't simply memorizing sentences, how does it generate useful answers to completely new questions?

at which point does pattern recognition become something that looks like reasoning?

i am also not sure where the boundary is between prediction and understanding


## what do i hope to understand by the end of this investigation?

by the end of this investigation, i want to be able to explain what a language model is in simple language without relying on buszzwords or vague anologies

i want to understand enough that i can tell where common misconceptions come from, where my own mental model was incomplete, and what actually happens when a language model produces a response
