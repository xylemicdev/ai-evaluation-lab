# question

## investigation question

people often describe incorrect ai responses using a single word: "hallucination"

is that actually one kind of failure, or is it a label that hides several different kinds of mistakes?

if different failure types exist, how can they be distinguished through observation alone?

---

## why this question matters

evaluationg an ai system requires more than deciding whether an answer is correct or incorrect

two answers can both be wrong while failing for completely different reasons

if those failures are treated as identical, useful information is lost

this investigation aims to determine whether language model failures can be grouped into distinct categories based on their observable behavior, rather than assuming every incorrect response is simply a hallucination
